# 本地音乐风格资料

`catalog.json` 是固定在 Git 中的本地资料，不在运行时请求原网站。

参考来源：[汪叔音乐风格地图](https://wangshubianqu.com/music-map/)。本次收录 1023 个具体风格、29 个分类入口、2641 条关系和 5385 条曲目记录，保留名称、别名、分类、年代范围、曲目与来源链接等事实信息。文件记录采集时间、原始公开索引 SHA、detailVersion 和完整性结果。

不包含原站程序、长篇介绍、历史文章、图片或录音。节奏、和声、配器与制作提示由本地规则和独立编写的 21 个重点档案整理；这些是编曲参考，不是对当前工程的分析，也不是对某个音色产品的预设映射。具体风格的历史资料可从档案中的出处继续阅读。

生成入口为 `scripts/library/import_style_atlas.py --details`，读取公开索引及公开详情，只保留事实字段与技术标签，三连接、有界超时及重试；已有 catalog 时拒绝覆盖。此入口是开发维护命令，软件启动和 AI 查询都不会调用它。`scripts/library/curate_styles.py` 可独立重新应用本地编曲说明，重复执行保持条目不累加。维护后检查统计、引用完整性、来源及 Git diff，再发布新固定资料。

收藏与最近打开的风格保存在本应用的浏览器配置中，不写音乐工程；删除某个音乐工程不删除风格资料。代表曲目提供搜索跳转，本次没有缓存音频。
