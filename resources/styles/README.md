# 本地音乐风格资料

`catalog.json` 是固定在 Git 中的本地资料，不在运行时请求原网站。

本库随源码公开。项目原创的资料整理、介绍和编曲建议采用 **CC BY 4.0**，可以转载、修改和商用，按许可保留署名并说明修改。推荐署名：`Music Learning contributors — 音乐风格库，CC BY 4.0`。许可全文见 [LICENSES/CC-BY-4.0.txt](../../LICENSES/CC-BY-4.0.txt)，范围见 [NOTICE.md](../../NOTICE.md)；外部作品保持自身权利，来源链接、条目 provenance 和资料引用继续保留。

参考来源：[汪叔音乐风格地图](https://wangshubianqu.com/music-map/)。本次收录 1023 个具体风格、29 个分类入口、2641 条关系和 5385 条曲目记录，保留名称、别名、分类、年代范围、曲目与来源链接等事实信息。文件记录采集时间、原始公开索引 SHA、detailVersion 和完整性结果。

介绍根据各条目的具体资料分别概括，编曲建议独立编写。每个具体风格有自己的介绍及至少两个维度的可执行提示；29 个分类也有各自的浏览说明与起步建议。不会为填满栏目强行添加主唱、贝斯或和弦建议。编曲提示保留简短的资料特征 `basis` 和对应来源字段 `source_ids`；这些字段是本条原始详情的 JSON Pointer，不是跨风格通用关键词。

旧的 38 条关键词模板及仅覆盖 21 条的补丁路径已移除。`scripts/library/fetch_style_sources.py` 有界获取具体来源，最多三连接，可按原始响应 SHA 续跑；研究缓存放在 `runtime/maintenance/style-content-20261023`，不随应用分发。产品不包含原站程序、整篇原文、图片或录音。

`scripts/library/build_style_content.py` 接收完整的独立文案分片和来源记录，显式替换全部旧介绍／提示。缺项、旧模板残留、去掉风格名后的重复正文、来源字段为空或不属于本风格、SHA 不匹配都会阻止写入。`scripts/library/import_style_atlas.py` 仅保留为此编译器的兼容入口，不再产生文字。`audit_style_content.py` 可独立复查。长度只作阅读提示，不靠字数或关键词冒充内容质量。以上均为维护入口，软件启动与 AI 查询不会联网抓取或生成文案。

`catalog.json` 是发布后的固定文本；每条 `provenance` 区分资料概括和编曲建议，保存来源详情 URL 与原始响应 SHA。修改后应检查全库覆盖、重复句、相邻分支差异、来源对应与 Git diff，再发布不可变资料。

收藏与最近打开的风格保存在本应用的浏览器配置中，不写音乐工程；删除某个音乐工程不删除风格资料。代表曲目提供搜索跳转，本次没有缓存音频。
