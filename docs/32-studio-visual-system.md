## 视觉体系

- `style.css`：共享颜色、字体、圆角、输入、按钮、下拉、焦点、滑杆、滚动条及音乐库。底色 `#101011`，面板 `#171719`，控件 `#202023`，主文字 `#e9e8e6`，辅助文字 `#929299`，暖橙强调色 `#ff9555`。
- 本机字体优先 Inter / Segoe UI Variable / Segoe UI / Microsoft YaHei UI，不下载字体。正文 13px，主要标题 18px，面板标题 12–14px；时间和数值使用等宽字体。没有重新引入宣传大标题。
- 圆角按 5 / 9 / 14px 分级，面板用轻分隔线而非重复粗边框；移除金属渐变、按钮斜面及多个旧主题互相覆盖。弹层保留必要阴影。
- `Icon.tsx`：同一笔画、尺寸和视图框的本地 SVG 图标；播放、暂停、返回、聊天、卷帘、混音、版本、分析、发送等采用统一图形。纯图标保留按钮名称与键盘访问，图形本身从辅助技术隐藏。
- `visual.ts`：音轨、编排、音符、力度和混音共用色板；画布颜色与 CSS 面板一致。颜色不写入音乐快照，不改变原有乐器映射。
- `workbench.css`：工作台、工具栏、音轨、可调整边界、音色与效果、版本和分析。
- `daw.css`：编排、钢琴卷帘、琴键、编辑工具、力度与混音推子。
- `discussion.css`：聊天正文、Markdown、引用、消息气泡、输入框和设置弹层。

删除重复覆盖文件 `studio.css`，其仍在使用的布局和交互规则已并入上述模块。主页与工作台从同一个基础样式入口加载；无额外 UI 依赖。支持键盘焦点和系统减少动态效果偏好。

## 具体画面

主页重新绘制应用标识、导入入口、歌曲列表、工程标识、状态、试听播放器和任务记录；工程标识是图形符号，不伪造封面或音乐波形。播放器保留原曲/重建及电平匹配。

工作台统一播放控件、时间显示、轨道选择、独奏/静音、页签与编辑工具。侧栏的讨论、音色与效果、版本、分析共用字阶和表面。保留工具栏自动收起/锁定、各面板分隔条、讨论放大和底部输入。

编排中的未编组 MIDI 摘要从音符密度柱状图改为真实音高、起点与时值的缩略图，仍标识未编组，不创建虚假的 MIDI 片段。相同屏幕像素位置的音符只合并绘制，不改工程数据。每条声部缓存一个 SVG path，随快照/可见区间/宽度重建，播放光标移动不重新生成全部缩略几何。

卷帘与编排网格按显示比例过滤过密线条，标尺文字保留，吸附仍使用原音乐网格和时间契约。音符选中、播放头、琴键与力度采用同一色彩规则。
