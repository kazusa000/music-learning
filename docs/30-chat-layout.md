# 讨论侧栏的空间与输入

2026-10-20。用户反馈会话、模型、范围、权限等控件占据大部分侧栏，真正的输入和回复区域过小。本次调整整个侧栏的高度分配，不修改音乐或对话协议。

## 当前布局

- 侧栏页签高度 38px，会话/模型/新会话/放大/菜单为一行 42px 工具条，移除重复的“音乐助手”标题和常驻笔记切换行。
- 回复区自动占满剩余高度、单独滚动。取消原先固定 240px 的历史高度；旧 `discussion.history-height` 偏好不再限制布局，也不删除用户的原偏好。
- 输入区固定在侧栏底部。上沿分隔条可向上拖高输入框，键盘微调/双击复位沿用 PanelResize；新偏好 `discussion.input-height` 默认 84px、最小64px、最大320px且不超过讨论面板高度40%，窗口变矮时动态夹紧。
- 底部一行显示实际音轨、整曲/选区、讨论/改编模式和发送。点击范围可修改选区/整曲、整轨权限和登录方式；设置作为回复区上方的弹层，不挤压回复，也不挡输入框。菜单可切换笔记、刷新模型或把输入存为笔记。
- `⤢` 放大讨论，保留草稿与当前会话，`⤡` 恢复制作布局。切换其他侧栏页签也会还原制作区。
- Enter 发送，Shift+Enter 换行，中文输入法的确认回车不发送。对话按钮/菜单的空格用于激活控件，不触发音乐播放；其他区域空格播放的原行为保留。
- 其他侧栏页使用独立滚动容器。修复旧样式仅在1201px以上提供弹性侧栏的问题，并用 `minmax(0,1fr)` 约束制作区网格行，避免1000px窗口里中央编辑器把输入框顶到屏幕外。900px以下采用可滚动的分区布局，放大讨论时占满工作区。

实现为 Discussion.tsx、discussion.css 与 Workbench 的视图状态。没有新增 API/SDK/CLI 操作、迁移或工程修改，仍为55项领域操作/11类任务。权限、版本绑定、发送、取消和重试沿用原接口。

## 验证

TypeScript/Vite 构建通过。真实前端配模拟对话的 chat-layout-v8 检查会话、模型、Markdown、引用、草稿保留、设置不挤回复、放大/还原、笔记菜单、中文输入法与 Enter/Shift+Enter，且对话控件空格不播放。桌面单次布局测量如下，单位为CSS像素：

| 窗口 | 侧栏可用高度 | 回复区 | 默认输入框 |
| --- | ---: | ---: | ---: |
| 1600×1100 | 997 | 774.6 | 84 |
| 1366×650 | 547 | 324.6 | 84 |
| 1000×768 | 665 | 441.6 | 84 |

390×844放大讨论、无横向溢出及输入可见通过。报告与桌面/窄窗口截图在 `data/benchmarks/chat-layout-v8`。

相关浏览器回归：chat-layout-stream-v1（模拟流式、停止/重试、登录记忆）、chat-layout-panels-v2（拖动/恢复、卷帘滚动和缩放）、chat-layout-toolbar-v2（工具栏/侧栏）、chat-layout-instruments-v2（目录选择与草稿/声部校验）通过。未新调用真实provider、音乐模型、正式渲染或NAS。正式head仍为34cd8c6c9e96492092533ec8aab1a3de、9,378音符；后端99项是上轮证据，本次仅前端变更未重跑后端全套。

早期检查暴露放大讨论的交叉轴高度、弹层挡输入框、中等宽度网格行溢出，均修复后重查；工具栏检查改为模拟空讨论列表以避免用户已有历史干扰快捷建议场景，隐藏的整轨权限需先展开设置再检查。早期失败报告保留，没有改标通过。

用户本轮明确取消额度停止规则；此前29%停止记录保留为历史，不据此阻止本次开发，不调用重置卡功能。
