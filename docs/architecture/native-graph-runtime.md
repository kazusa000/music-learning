# N6运行图实施记录

状态：N6阶段验收已完成，DAG/侧链/PDC/自动化、后台资源替换及共用流式导出取得独立证据，见阶段报告（历史文档见 Git）。**不保证所有结构/总延迟变化无缝；N7及默认切换仍未完成**。N1–N5的独立轨道路径保留。

现有离线renderGraph按拓扑逐节点生成WAV再读取，不能直接搬到设备线程。本阶段新增原生后台图生产器，设备仍只消费有界已备好的块。第三方DSP在隔离worker；控制消息仅元数据，输入/侧链/输出走SID ACL保护的共享内存和原生事件。插件卡死时设备及无关路径继续，当前失败路径给出状态，不使用旧声音冒充成功。

选择项目采样率作为图DSP时钟，Master后统一重采样到设备采样率。逐节点计算输入到达延迟：主/发送边补齐至该节点最大输入到达时间；侧链按目标插件前置链延迟对齐。节点自己的音符、片段、参数和playhead都按相同来源时钟调度。Master预滚并移除总图延迟，定位/循环保持源样本语义。采样精确的插件曲线与混音曲线分别处理，不能把块首值当完整线性自动化。

worker节点模式一次有一份输入所有权；生产器按拓扑层并行提交，完成/序号/epoch匹配后读取输出，不覆盖仍在处理的输入。实时等待受块预算约束，迟到或故障节点单独记数/静音，后台判定卡死并释放自己的Job Object。离线导出使用同一图/调度/增益语义，流式写WAV而非整曲内存，冻结revision/mixing_version；插件失败应让导出失败，不能交付缺轨成品。内存含边延迟与IPC，默认总音频缓冲预算256MiB，报告实际分配。

资源或链变化新建相关worker；兼容音符/参数更新保留进程。纯参数变化不重触发持有音符，无关声部不能因其他声部修改而重开/重触发。新图在生产器块边界生效，desired/applied_revision依据实际程序/块确认。图延迟变化要重新预滚，量化其耗时，不能把旧路径或高延迟插件的物理限制冒充所有图都能瞬时修改。

必须一并核对：直接音频重叠片段应相加；tempo/meter/loop playhead；声部/总线/发送/侧链和solo路径；线性/阶跃参数与推子自动化；多路径和串联PDC；播放中参数/音符/资源改变；崩溃/卡死/迟到隔离；冻结基准、参考响度与峰值保护只施加一次；实时/离线夹具逐样本比较。现有SessionGraph的回调仅有软顶限幅，旧浏览器监听还包含压缩/过采样，N6须查清实际校准函数再迁移，不能先宣布响度一致。

发布前固定engine/worker构建身份与ABI，避免进程运行时加载另一版本的worker；旧ml_audio_host、ml_track_host及Pianoteq固定库不重建替换。现有files探针在N7使用前要适配当前MIDI优先编译，独立准备资源并固定worker，检查插件late/missing和applied_revision，不能沿用N2 file-only计数代替。
