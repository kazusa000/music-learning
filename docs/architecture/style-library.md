# 本地风格库

2026-10-23。范围：风格资料、分类／年代／特征搜索、收藏、关系地图、内置 AI 只读查询。工程案例与音色映射后续讨论，本阶段不接入。

## 界面与入口

主页左栏“风格库”，或 `/?view=styles` 打开独立浏览页；`&style=asi03` 可定位具体风格。工作台顶栏“风格库”打开模态参考页，编辑器保持挂载，关闭后原音频会话、位置与工程版本继续保留。模态窗口阻断工作台空格快捷键，避免浏览时意外播放。

分类栏、搜索／浏览区、档案区使用独立的紧凑布局；低饱和分类色、原创 SVG 线条图形和细边框沿用工作室皮肤，不加载外部图片或字体。侧栏与档案不显示原生滚动条，鼠标和中键仍可滚动。较窄窗口把档案改为可返回的单页详情。

目录按需加载；主页不会预取风格资料。风格页只读轻量目录，不额外读取选中工程的完整 MIDI／渲染记录。图形模块约 16.7 KB 原始 JS／6.2 KB gzip，独立于主入口。卡片每次显示 48 条，可继续加载；搜索、年代筛选和收藏筛选在本地完成。收藏使用 `studio.style-favorites.v1`，最近查看使用 `studio.style-selected.v1`。

关系地图展示年代与分类，1900 年以前压缩显示；选中风格才突出其直接关联，避免把 2641 条连线同时覆盖在画布上。支持拖动、右／中键平移、滚轮／按钮缩放与恢复全图；“层次”是二维层次排列，不冒充原站三维引擎。

档案包含形成时期、速度倾向、风格画像、具体编曲提示、来源与影响、曲目跳转和资料出处。画像与提示分层排版，只显示实际有内容的音乐维度；不为凑栏目填入通用人声／贝斯／空间建议。完整资料来源与本地说明范围见 `resources/styles/README.md`；原站长篇文字、图片与录音未打包。

## API、SDK、CLI 与助手

四个操作共用 Service 和生成契约，无数据库迁移：

- `styles.index {}`：全目录、分类和简要技术标签。
- `styles.get {style_id}`：完整本地档案与直接关系。
- `styles.graph {}`：节点及有方向的关联数据。
- `styles.query {action:"search"|"detail"|"related",query?,style_id?,category?,limit?}`：默认 12、最多 30 条，供程序和 AI 检索。

既有 SDK／CLI 的通用 execute／command 入口可直接调用上述操作。助手新增动态工具 `style_query`；先查找 ID，再读详情。工具不要求工程修订，不修改项目，不加载插件、不调用音乐模型；工程本身的问题继续通过 `music_query` 读取实际 MIDI，不能把一般风格描述当成本曲证据。关系、曲目与出处在模型查询结果中有数量上限。

资料由只读 `style_library` 模块缓存，源文件随不可变发布固定。AI 不需要外网读取原站；库中无工程案例或预设选择接口。
