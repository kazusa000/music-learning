# 工程加载进度

进入编曲、扒带工程以及切换原曲／重建时，共用顶部紧凑加载栏；元数据尚未返回的直接入口也有即时反馈。它显示当前阶段、音源就绪数量、耗时与逐轨详情；完成后1.2秒收起，失败持续显示原因并可显式重试。原曲没有插件时保留音频准备状态。

## 进度来源

`projectLoading.ts`读取既有`NativeTransport.state`，不增加轮询、下载、解码、模型或导出操作。读取配置阶段没有服务端百分比，显示不定进度。插件数量取原生音频图实际返回的节点（包含总线效果），启动前仅以有内容且未冻结／旁通的工程插件作等待列表。每个节点以`load_stage`说明读取插件、恢复音色、准备播放；百分比按就绪节点数计算，不按耗时模拟。

只有`project_id`、`revision_id`、`view`匹配目标，原生状态为ready，全部实际节点ready且`applied_revision`等于目标时才显示100%。旧工程、旧视图和旧修订的就绪状态不会提前完成；交接阶段保持低于100%。空轨和冻结音轨不因缺少插件状态永久等待。

失败原因取原生插件／control_error和打开请求错误。重试使用已有`open(target,true)`，重新准备当前播放图，不创建音乐修订或导出文件。进度显示不影响播放、音量、静音和独奏的既有控制队列。完成或失败后停止耗时计时器。
