# 开源准备

本页说明源码共享的范围与入口。实际目录整理的验收记录见[源码目录检查](../benchmarks/source-layout-preparation.md)。项目软件采用 AGPL-3.0-only，乐器图片与风格库的原创内容采用 CC BY 4.0；完整范围见 [NOTICE.md](../../NOTICE.md)。

## 源码与本机目录

- Python 依赖输入／锁文件集中在 `requirements`，安装入口、包元数据、分析及导出指纹使用同一目录。
- 早期 P0–P6 人工验收工具在 `scripts/probes/legacy`；现行模型 worker 和音源任务保留稳定入口。
- 根目录 README、贡献说明和脚本导航区分了产品源码、本机数据、构建产物及历史诊断。
- 示例配置去掉固定 E 盘路径；Git 忽略规则补充任意后缀的 `.local.*`、私有配置目录与崩溃转储。

## 只读审查入口

`scripts/maintenance/audit-source-tree.py` 只读检查 Git 跟踪的文件，输出目录统计、常见令牌／私钥模式命中位置、本机绝对路径所在文件和不应共享的数据文件名。不会输出匹配到的密钥内容，不读取被忽略的用户工程或音源目录。

使用 `--history-paths` 检查全部本地引用的历史文件名，使用 `--history-text` 扫描准备推送的 `HEAD` 所能到达的全部唯一文本 blob，包括当前已删除或被替换的内容。二进制与超过 16 MiB 的 blob 单独计数；存在超大文本未查项或凭据模式命中时命令返回失败。模式检查不覆盖所有凭据类型，不能等同完整安全审计。

输出保存在指定的 `runtime/maintenance/<task>` 目录，不提交到 Git；不要将本机配置、报告、插件或音源加入跟踪以便审查。发布只推送选定分支，不使用 `--all` 或镜像推送把其他工作树的分支一起发布。

## 公开范围与运行边界

- **软件**：根目录 `LICENSE` 是完整 AGPLv3 文本；Python 与前端包元数据使用 SPDX 标识 `AGPL-3.0-only`，与当前 JUCE 开源许可路线配套。
- **展示与资料资源**：`resources/instruments`、`resources/styles` 的项目原创内容随源码公开，使用 `CC-BY-4.0`。图片登记与风格库顶层元数据记录许可和署名，原图片 SHA、风格正文及来源不变。外部材料保持各自原声明。
- **首次运行与发行包**：当前工具链和部分组件按本机验证的版本固定。源码准备说明已经区分可执行的 Python／前端准备与尚需单独配置的原生、AI、模型和插件部分；没有声称全新电脑一键可用。
- **本机历史说明**：`AGENTS.md` 与 `docs/benchmarks` 保留当前协作及验收所需的本机边界和历史路径。这次没有删除证据或把“没有提交运行数据”扩大为“所有历史文本都已脱离本机环境”。

依赖许可记录见 [THIRD_PARTY.md](../../THIRD_PARTY.md)，各组件的运行与资源配置由使用者自行准备。这些发布决定不影响当前本机应用。
