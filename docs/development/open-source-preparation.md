# 开源准备

本页说明源码共享的范围与入口。实际目录整理的验收记录见[源码目录检查](../benchmarks/source-layout-preparation.md)。公开远程仓库、推送和许可证选择是单独的发布决定。

## 源码与本机目录

- Python 依赖输入／锁文件集中在 `requirements`，安装入口、包元数据、分析及导出指纹使用同一目录。
- 早期 P0–P6 人工验收工具在 `scripts/probes/legacy`；现行模型 worker 和音源任务保留稳定入口。
- 根目录 README、贡献说明和脚本导航区分了产品源码、本机数据、构建产物及历史诊断。
- 示例配置去掉固定 E 盘路径；Git 忽略规则补充任意后缀的 `.local.*`、私有配置目录与崩溃转储。

## 只读审查入口

`scripts/maintenance/audit-source-tree.py` 只读检查 Git 跟踪的文件，输出目录统计、常见令牌／私钥模式命中位置、本机绝对路径所在文件和不应共享的数据文件名。不会输出匹配到的密钥内容，不读取被忽略的用户工程或音源目录。

这项检查不涵盖历史 blob 内容，不作为完整历史密钥审计。输出保存在指定的 `runtime/maintenance/<task>` 目录，不提交到 Git；不要将本机配置、报告、插件或音源加入跟踪以便审查。

- **展示与资料资源**：当前乐器图片登记有 203 项，来源标记为 AI 生成，其 `license` 字段尚为空；风格资料另有来源记录。发布时需要决定这些内容随源码提供的方式，不能直接把源码许可证写到全部资源上。
- **首次运行与发行包**：当前工具链和部分组件按本机验证的版本固定。源码准备说明已经区分可执行的 Python／前端准备与尚需单独配置的原生、AI、模型和插件部分；没有声称全新电脑一键可用。
