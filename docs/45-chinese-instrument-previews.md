# 中文音色目录与独立试听

2026-10-21。型号、变体、来源与音色参数用中文显示；型号和变体各有独立试听按钮。目录选择仍为「乐器类别 → 型号 → 变体 → 确认应用」。

## 使用

- 型号右侧的 ▶ 播放该型号的代表变体；变体右侧的 ▶ 播放具体音色。试听区域显示实际音色名、等待/加载状态、停止与独立音量。
- 点击试听不选择变体、不应用到轨道。新试听会停止旧声音；停止、自然结束、失败、换轨和离开页面会恢复工程监听。确认应用会先停止短句试听，再走现有三阶段加载。
- 工程继续走原来的播放时钟；试听开始时只把本机工程总监听暂时降到 16%，结束恢复。不会写轨道推子、静音、独奏、播放位置或音乐修订。
- 音源未缓存时等待独立准备，缓存命中后直接读取短音频。切换很快或停止等待时，晚到的响应不能重新开始播放；后台生成的缓存可供以后复用。

## 中文与后续导入

`instrument_localization.py` 提供统一中文词表和原厂型号映射。当前 489 个可选预设、53 型号组的型号及变体名称都能完整解释为中文，不以英文原名作为列表回退。C7、D6、W1 等型号编号仍保留。原始 `name`、`variant_name`、型号、插件参数 ID/值及 `preset_id` 不改；原英文放入悬停详情并参与搜索，中文也可搜索。

API 增加 `display_name`、`display_variant_name`、`model.display_name` 与 `source.display_name`。当前音色、音轨副标题、选择确认、加载状态和参数面板使用中文显示。`instruments.labels` 只批量查询当前使用的预设和参数名，不要求前端先下载整库。

所有导入条目保留统一 `model_spec`，并由 `classify/with_model` 加入中文视图及版本化 `preview_spec`。Keyscape 索引/增量验证、Pianoteq 9.1.2 接入、旧 Pianoteq 适配和通用采样/合成器目录共用中文准备函数。新库可提供：

```json
{
  "labels_zh": {
    "model": "新型号的中文名称",
    "variant": "自然",
    "library": "来源库的中文名称"
  }
}
```

导入目录下可选的 `labels.zh-CN.json` 使用「预设 ID → labels_zh」结构。词表无法完整解释的新名称，先由导入适配工作补齐中文映射，再发布；不会靠中文占位名把新音色塞进选择器。已验证条目的中文信息会持久保存。通用目录仍兼容保存未验证库存，前端型号/变体列表仅查询已入库验证的音色，不新增筛选开关。

后台观察发布目录的变动，自动为新入库条目加入同一个试听队列：先预热各型号代表，再准备其余变体。实际点击优先于后台预热。音源资源始终从用户指定的 H 库读取，本次不改写现有目录、插件、样本或原验证报告。

## 库级试听与缓存

试听使用独立 SQLite 队列和进程锁，缓存位于 E 项目运行数据的 `data/app-data/instrument-previews`，不向正式工程创建任务、修订或素材引用。API 启动后台线程协调，真实处理仍在独立原生 VST3 子进程；Windows Job Object 管理进程归属并记录 PID/创建时间，单次有超时，关闭时停止自己的子进程、下次恢复未完成准备。

短句由确定性模板产生：贝斯低音线、打击节奏、槌击短句、键盘分解和弦等，音高限制在音色真实登记音域内，包含力度变化和尾音。同类变体用同样短句。真实宿主加载选定完整状态并检查插件与声源身份，拒绝无声或削波输出；只生成这段短句，不调用整曲制作或音乐模型。

音频以单个固定增益靠近参考 RMS，限制峰值，并作极短首尾淡化，保留演奏动态。成品使用 PCM16 WAV；不会修改音源原始状态或原厂输出。

缓存键包含短句版本、宿主摘要、预设/插件/运行依赖、样本清单和声源身份；中文名称不参与音频键。首次及文件 stat 变化后复核文件 SHA，已装大库沿用不可变清单检查；读取缓存也检查来源和音频 SHA。相同音色请求合并，幂等键复用不能改内容，重试使用 generation 防止取消后的旧结果发布。

缓存默认上限 512 MiB，优先保留点击过和型号代表音色，近期播放文件短暂保留。仅回收新试听目录内生成的成品，原库、原验证音频及此前清理被拒目录均不进入此回收。每次准备的原始 WAV、重复状态副本在结束时清掉，只留下成品和小型诊断。

## API、SDK 与 CLI

共 76 个可发现操作。新增的库级操作与原 `jobs.submit` 工程任务分开：

- `instruments.labels`：中文名称与参数批量查询。
- `instruments.preview.prepare`：`preset_id`、可选 `retry`；返回准备状态或缓存 URL，写入只发生在试听队列，要求幂等键，无工程或 revision 参数。
- `instruments.preview.get/cancel`：以 `preview_id` 查询或取消尚未完成的准备。前端停止播放只停止本次本机试听，已开始的共享缓存准备可继续复用。
- `instruments.preview.stats`：就绪、等待、准备、失败数量及缓存字节/上限。
- 音频地址 `/v1/instrument-previews/{preview_id}/audio` 沿用本机会话认证与内容检查。

SDK 对应 `instrument_labels`、`prepare_instrument_preview`、`instrument_preview`、`cancel_instrument_preview`、`instrument_preview_stats`；CLI 使用同名 `call` 操作。Python 权威契约已生成 TS/JSON Schema，无工程数据库迁移。
