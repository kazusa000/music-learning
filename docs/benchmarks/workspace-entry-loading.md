# 工作区加载条只属于首次进入

2026-10-24，用户要求加载条只在进入工程时显示，时间轴定位和原曲/重建切换不再显示。

原实现一直挂载 `WorkspaceLoading`，按工程/版本/视图/连接 epoch 更新 key，并在播放器 phase 改变时重新显示。正常定位、视图切换或图状态短暂交接因此会触发工程级提示。

工作区现在按已存在的 project React key 管理首次进入生命周期：首次实际就绪后卸载加载条，此次工作区内的跳转、切换、编辑和重连不再挂载；退出再进入会重新开始。首次进入失败仍保留进度与重试，已进入后的真实错误通过工作台普通提示显示，音轨实际状态不被隐瞒。未改变播放、seek、音源加载或音乐持久化规则。

验证覆盖 TypeScript 检查、前端构建、进度规则与隔离浏览器回归。真实隔离工程 API 配合可控原生遥测，检查首次读取、加载阶段/计数、初始失败/重试、窄窗、三次原曲/重建切换、暂停及播放中的六次时间轴跳转，以及后续错误和退出再进入。MutationObserver 确认工作区操作期间加载条新增挂载数为零。未加载实际插件或播放正式音乐，不把遥测注入当成真实音频验收。2 项 pytest 通过，Ruff 通过；夹具修正前失败日志保留于测试报告。
