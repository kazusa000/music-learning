## 305 秒真实曲目

使用 P0 已有的本机 FLAC 副本，44.1 kHz / stereo / 13,450,500 samples。源 SHA-256：`a870febc293b50604bb68ce7d50a536593ff61c18bbad4cbb9efebc36e62db43`。本轮不从 NAS 重新读取，不写远端标签/清单/封面或音频。

通过正式 SDK 一次导入并自动排队，重新执行三模型；七阶段全部是缓存 miss。源文件大小/mtime 在导入前后一致，原始字节与保存的 source asset 摘要一致。最终保存 4 条全长 stems、6 个符号声部、9,378 个音符、899 条拍点/和弦/调性/段落候选、6 个完整插件实例及串行路由；不是将 P0 已完成输出手工登记为 ready。

| 模型 | 此次完整执行耗时 | CUDA allocated 峰值 |
| --- | --- | --- |
| Demucs | 11.235 秒 | 551.3 MiB |
| MuScriptor medium | 209.593 秒 | 2,351.2 MiB |
| SheetSage2 | 35.281 秒 | 3,380.3 MiB |

MuScriptor 61/61 块，原始 NoteStartEvent 与 MIDI 音符均为 9,378，无数量差；SheetSage 两个接受窗口连续覆盖 0～305 秒，原始事件和模型诊断保留。数字是本次进程/配置结果，不能外推其他曲目或主观准确率。

含原生混音、六条逐轨、波形和完整校验的整曲任务约 381.66 秒。混音 13,538,700 samples / 44.1 kHz / 307 秒（显式 2 秒尾音），peak 0.18584，rms 0.02462，clipped samples=0；全部逐轨也通过长度、非静音和削波检查。真实 Surge XT / sfizz 状态独立保存，逐轨恢复状态摘要核对；声音是默认替代音色，没有还原原唱/原始音源。

经实际 HTTP 逐一读回 120 个关联素材，合计 1,858,474,123 bytes，全部大小/SHA-256 正确，读回约 13.38 秒。包括原始模型输出、音频、状态、资源和 manifest，不仅检查数据库行数。

## 194 秒原创曲与实际恢复

使用 P0 原创 `whole-song-v2/mix.wav`，48 kHz / 9,312,000 samples，SHA-256 `5413cc2a8faa8a7a0ee186cf58a5654311ac44406289ac261e72aa6c88da2131`。它与真实参考曲目在音色、节奏和配器上不同，仍不能由两个样本推断所有音乐的还原质量。

真实首次转录进度出现后停止服务。恢复后的 normalize/Demucs 为 cache hit；未完成的 MuScriptor 不复用半成品，重新完成 39/39 块。最终任务 attempt=3，全部七阶段成功；保存 4 stems、2 个模型合并声部、1,252 个音符、407 条候选和 2 个完整插件实例。原始起音 1,257，5 个零时长结束未形成 MIDI 音符，数量差作为真实质量问题保留。

一次完整 MuScriptor 69.328 秒，SheetSage 52.843 秒；复用的 Demucs 原执行 7.688 秒。最终混音 196 秒（含尾音），peak 0.10979、rms 0.01788，无削波。通过 HTTP 回读 107 个关联素材、986,941,587 bytes，大小/摘要全部正确，约 8.39 秒。

恢复探测第一版在 stop 返回后立即断言全部 PID 已消失，触发了退出时序竞争；事后核对无遗留模型进程。修正探针为有界等待，并保留停止前阶段/受控 PID 记录，再真实执行一次中断。修正版核对 16 个受控进程全部退出，attempt 2→3，已完成两阶段复用、转录重算后成功。没有预写成功状态或更改音乐数据来制造通过；旧 partial 文件和任务历史保留。

## 候选版本、人工修订与恢复

在独立验收工程中，把一个有音高声部音符从 45 改为 46，保存为带 user/corrected 来源的新 revision。新分析完成时 `adopted=false`，当前 head 和该修订快照摘要不变，旧版本仍保留人工音高校正。

候选分析实际复用前四阶段、单独生成新版本的完整混音/逐轨/状态。随后通过显式 `preprocessing.adopt` 核对素材并采用候选；旧校正 revision 仍可读取。这里验证版本保护，不宣称人工校正版本已经生成新声音或完成 P3 编辑工具。

最后对 305 秒与 194 秒的正式工程实际停止/重启服务，head、快照摘要、9,378 / 1,252 个音符、所有版本 ID、publication 及完整状态资产摘要一致。另生成了通过 integrity_check 的 SQLite 元数据备份；包含音频/插件依赖的完整工程打包恢复仍在 P6。

中央波形与卷帘共用原始样本零点，不量化转录。界面明确区分音频 stems 与 MIDI 声部，标注模型结果待核对、合成器/鼓音色替代和人声旋律重放。卷帘是只读整曲预览；精细缩放/编辑、A/B/循环和完整制作仍在 P3。

## 当前界限

ready 只证明材料齐全、技术校验通过。P0 已发现的漏音、鼓漏检、声部合并、力度/控制器缺失、分轨串音、和弦/结构歧义继续存在；本轮没有人工听辨，也没有因界面可见就声称模型更准确。

弱起从模型短下拍跨度推断，末端映射有明确 estimated 锚点。原生 PPQ 当前仍以音频零点起算；完整弱起 transport、任意复杂路由、插件制作、局部编辑、同步 A/B、正式 Codex 对话和跨工程创作均不计入 P2 完成范围。
