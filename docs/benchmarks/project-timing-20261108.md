# 工程内 BPM 与拍号

2026-11-08。播放栏新增速度与拍号控件，和新建编曲使用相同节拍单位，保留现有暗色、紧凑工具栏。BPM 输入在 Enter／失焦时提交，Escape 取消；支持常用拍号与自定 1–32 拍、1/2/4/8/16/32 分母。

## 共享规则

`edits.apply` 的 `project_timing` 在同一事务中完成编辑、保存与撤销记录。全局改速缩放实际 MIDI 音符、MIDI 片段、控制事件及音乐自动化；音高、力度、身份和节拍位置保留。按指定播放位置的 BPM 比例缩放已有速度曲线，不把原来的变速抹成固定速度。只改拍号重排小节而不移动音符。

慢速后工程时长覆盖全部事件，保留空编曲的音乐长度。原曲与人声音频不拉伸；`source_duration_samples` 将原录音长度与可延长的编曲时间轴分开，仍和实际源文件元数据严格核对。原始参考、stems 与音源状态不改。新建参数 `beat_unit` 默认为 4，6/8 采用每小节三个四分音符长度，旧调用保持兼容。原曲及历史版本中的控件只读。

## 验证

- 48 项相关短回归通过（21.37 秒），覆盖时间转换、创作工程、编辑／撤销、原曲参考与助手工具；未重跑已有独立原音频发声测试。
- 最终源码与候选前端的 10 项定向检查通过（6.36 秒），包括源文件长度不可篡改、60／240 BPM、采样时间与节拍时间 MIDI 同步、片段、控制事件、自动化、原曲长度、变速曲线、重开和撤销。
- 实际 Edge 自动化用 E 盘 MLFixture，经原生引擎边播放边把 120 BPM 改为 60 BPM，修订应用后仍有实际设备电平；切换至 3/4 后音符时刻保持，暂停正常。自定 5/16、Escape、撤销重做、重开均通过。截图在 DPR 2.5 的 4K 和 1120 CSS 像素窗口核对控件与窗口按钮边界；截图人工查看了窄窗，未做人耳音质判断。
- TypeScript、契约漂移、Ruff、前端构建，以及 6/8 小节线和变速位置显示单元通过。既有 Vite 大 chunk 提示与 Starlette 弃用提示没有作为功能失败处理。

测试采用统一清理入口，隔离工程／浏览器／音频夹具退出清理，只保留小报告和截图。初期夹具的资源注册与录音元数据错误、截图选择器范围错误均保留原失败报告，修正后复验通过。没有调用音乐模型、正式渲染或 H 盘音源，也没有往正式工程写测试内容。
