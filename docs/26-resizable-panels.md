# 可调整面板和卷帘纵向操作

2026-10-19。用户要求每个主要框体能直接放大缩小，尤其 AI 侧栏宽度，并明确询问钢琴卷帘上下滚动和纵向缩放。

## 操作

- 主页歌曲列表、工作台声部栏、AI 侧栏：拖两块面板间的竖向分隔线。AI 侧栏左边界向左拖会变宽。
- 编排/混音/总览制作区域、钢琴卷帘、力度栏、AI 对话历史：拖底部横向分隔线调整高度；力度图形随栏高度缩放，鼠标坐标仍转换回原逻辑力度范围。
- 各分隔线双击恢复默认。聚焦分隔线后，方向键微调，Shift 加方向键较大幅调整，Home/End 到最小/最大；pointer cancel 恢复拖动前尺寸。
- 布局尺寸在本机 localStorage 记忆，不写工程版本。侧栏有最小宽度，编辑区保留空间；窄窗口面板堆叠以避免横向溢出。专注编辑仍可使用，保留手动设置的卷帘高度。
- 卷帘普通滚轮：上下移动音区；右侧竖向定位条可直接拖，↑/↓ 按钮移动六个半音。
- Alt + 滚轮：围绕鼠标所在音高纵向缩放。工具栏“音高缩放”的加减与滑杆也可操作，行距 8–40 像素。“适配音域”依据当前可见时间段的本声部音符适配，区间无音符时使用该声部全曲音域。
- Ctrl/Command + 滚轮仍是横向时间缩放，Shift + 滚轮仍是时间平移。音符拖动期间不切换缩放；输入框保留自身行为。卷帘及 AI 历史在滚动边界不继续带动整个工作区。

## 实现边界

PanelResize.tsx 提供受限尺寸、pointer capture、取消/键盘/默认恢复和可选视图记忆。Workbench 使用 ResizeObserver 取得容器实际宽度，并按窗口约束左右栏尺寸；DawEditor 提供视图区域/卷帘/力度高度，Discussion 保留独立历史高度。页面大小变化不修改音符、时间锚、插件、混音、渲染或试听意图，统一 API/SDK/CLI 仍为既有 52 项操作、11 种任务，无新增迁移。

纵向缩放先记录鼠标对应的音高坐标，在 useLayoutEffect 的 DOM 更新后恢复滚动位置，避免在旧 SVG 高度下被浏览器提前夹紧；显式音区定位会取消待执行的缩放定位。力度 SVG 在新高度下仍保留固定 viewBox，指针转换沿用既有编辑契约。
