# 当前工程素材保留与即时音量

2026-10-20。用户要求只保留当前工程和手动保存版本所需素材，并取消拖动音量时的任何保存请求。本约定覆盖以前保留全部内部修订素材、编曲页没有音量控件的说明。

## 音量与独奏

每条音轨直接提供音量推子和 dB 数值，编曲页操作只更新本窗口 WebAudio gain，不调用 mixer.set、mixing.save、versions.save 或 jobs.submit；松手、失焦和离开窗口也不会保存音量。不生成音频、不重启现有声音流。只有点击“保存版本”才把当前各轨 gain_db 与手动 checkpoint 在同一事务中记录；刷新前未手动保存的音量会恢复到工程值。音符、乐器等已有编辑的工作状态自动保存规则不变。

独奏控制与有效静音显示使用同一规则：有任意轨独奏时，其余轨静音按钮亮起并标注“独奏排除”；取消最后一个独奏恢复原手动静音状态。支持多轨独奏，删除轨道的过时 solo 不参与计算。编曲卡片、编排标签、独立混音页显示一致；临时独奏/静音不写入音乐版本。独立混音仍只有用户点击“保存混音”才保存。

## 素材回收

冻结迁移 0010 新增合并的维护请求及素材登记时间表。保留根仅为所有工程的当前 head 和用户命名保存的 checkpoint，递归保留原曲、当前引用的模型原输出/分析、插件完整状态及资源、当前可复用逐轨播放源、这些根的最新发布音频与每种格式最后一次显式导出。旧内部修订、历史任务结果/回执和 project_assets 的历史关联不再无限保活音频。

活动制作任务或对话期间不回收。新登记素材保留 60 秒，刚捕获尚未应用的音色与上传保留 15 分钟，避免发布与提交之间的竞态；到期自动再检查。工程编辑及任务终结只更新一条合并维护请求，不为每次操作产生一批清理任务。空闲 worker 先只读规划，在写锁内重新核对所有根、登记与任务状态再删除不可达 CAS；若当前必需素材缺失则停止回收。只删除项目自有 CAS 和终态任务工作目录，不遍历插件安装目录、H 音源库或 NAS。结束的原生播放会话释放其硬链接工作副本。

旧内部修订和对话文字仍供查看，但其未手动保存的音色/旧试听可能已回收，不能把它们当作可恢复版本；用户保存版本所需素材持续保留。恢复/新存已过期旧工作状态明确失败。保留当前/手动版本引用的原录音与模型原输出，不覆盖它们。

## API / SDK / CLI

统一 70 操作、11 持久任务类型。新增 storage.plan(project_id) 只读计算根、可移除数量/字节；storage.collect(project_id) 合并提交一次回收请求；storage.status(project_id) 回读 generation、pending、报告与下一次短暂素材到期时间。写操作保留 expected_revision 与幂等。versions.save 新增可选 track_levels，只在显式保存时原子记录推子值；旧客户端没有该参数时保持原请求幂等指纹。备份/恢复识别 0010。

## 验证

173 项独立后端回归通过，包括当前/手动根、旧回执不保活、短期捕获、并发 head 变化拒绝删除、活动任务阻止清理、缺失当前素材停止、工作目录边界、显式保存音量/幂等/无音频任务。第一次长测试路径造成 6 项原生宿主失败，改用本项目下短临时路径后完整 173 项通过；两项旧迁移断言升级到 0010。

TypeScript、生产构建、契约漂移、音量/独奏及既有 live-mix 控制器检查通过。独立 8774 原生双轨浏览器实测：持续播放中降 20 dB，实际轨道电平由 -12.04 降为 -32.04 dB，启动计数保持 1，另一轨维持 -12.04；独奏排除轨电平降至 -60 dB；取消恢复，手动静音保持；混音页显示相同。未保存刷新恢复工程音量；点击保存后刷新保持 -20.1 dB，仅增加一个 checkpoint 和一个含音量的内部音乐修订，未创建音频任务。没有生成整曲音频、调用音乐模型或真实 AI 推理。

小型证据位于忽略目录 data/maintenance/retention-levels-20261020。正式回收结果及 Keyscape 后台保护核对见部署后补充。
