入库和后续捕获/状态导入均核对实际 IComponent 中的**完整程序 SHA**。首次与重开均须与选定完整 FXP 一致，防止再次把默认钢琴记作电钢琴或吉他。验证结果复用现有持久队列和证据缓存，校验宿主、代码、插件、资源及侧车引擎；已入库状态可走现有快速捕获，不重复生成 WAV。缓存命中也新增侧车引擎检查。

## SDK 切换与实际常驻发声
