# 用户入口、桌面窗口与前端整改

2026-10-19。用户明确拒绝宣传式大字、开发编号、默认验证工程列表和绿色工作区，并要求实际检查整条使用流程。

## 已改

- 删除主页横幅及工作台/讨论/乐器页的宣传文案；歌曲名为普通标题，默认页面不显示 UUID、Git 号或插件状态摘要。版本用序号与时间表示。
- 主页重做为紧凑歌曲列表和详情，提供直接打开工程、原曲/重建播放器、可展开处理记录。播放器使用应用控件，不再直接展示浏览器原生白色音频条。
- 工作台采用中性深灰表面，声部保留少量识别色；明确原曲、重建、声部独奏和生成重建试听。S/M 改为可读文字。
- 主页和工作台均支持空格播放/暂停，阻止页面滚动；输入框/下拉框/可编辑文本内的空格仍正常输入。主页播放器互斥，离开主页会暂停，避免与工作台叠播。
- 未选轨道时打开钢琴卷帘会选择一个实际乐器声部，优先已有钢琴；不再留下空白编辑器。编排、卷帘、混音、乐器和 AI 的实际操作仍使用原领域服务。
- 再走查发现新版本会退回原曲模式：现有音符的版本默认保持重建目标，点击生成重建试听也明确切到重建。未渲染时按播放提示先生成，不能静默听回原曲并误以为修改没生效。
- 左侧声部双击也可直接打开对应卷帘；左栏标明“声部试听”，避免与混音台需要保存的工程静音混淆。
- start.cmd 默认打开独立应用窗口，使用本机 Edge app 模式、独立 profile 和受控进程归属；不打开普通浏览器标签。它仍然是 Web 渲染，不是已完成的原生桌面壳，也不因此获得实时音频引擎。显式 --browser 可供开发调试。重复打开聚焦自有窗口；没有可见窗口的残留所有者会被安全替换，stop.cmd 同时停止自有窗口和服务，不触碰用户个人浏览器。
