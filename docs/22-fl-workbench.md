## 界面

参考 [FL Studio 制作窗口的组织](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/main_windows.htm)、[Piano roll](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll.htm) 与 [Playlist](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/playlist.htm)：紧凑深灰面板、橙色播放/选中反馈、彩色音轨、绿色音符、节拍网格、独立编排/卷帘/混音台。采用本项目自己的样式和控件，不使用 FL 图标或品牌素材，不宣称兼容 FL 工程文件或拥有其全部功能。

顶部保留播放、循环、原曲/重建/A-B 和缩放；左侧声部，中央制作区，右侧 AI/音源/乐器/版本。桌面使用固定工作区与独立面板滚动，小屏保持可滚动布局。原 Canvas 波形/只读多轨摘要留在“总览”；单声部可编辑卷帘由 SVG 事件层提供。

## 已接通的操作

| 视图 | 操作 |
| --- | --- |
| 钢琴卷帘 | 选择声部；画笔画入并拖长；拖动音高/位置；右缘调整时值；Shift 多选与框选；橡皮/Delete 删除；Ctrl+C/V 在播放头粘贴；力度柱点击/拖动；精确音高、起止秒与力度属性。 |
| 编排 | MIDI 与音频片段显示/移动；右缘裁短；复制到后方；播放头分割；删除片段及其所属音符；循环区间内未编组音符建立 MIDI 片段。 |
| 音轨 | 新建乐器轨道；上移/下移或拖轨道标题排序；命名；显式删除所属实体和路由引用，历史仍保留。 |
| 混音台 | 音量推子和精确 dB、声像、工程静音/独奏；多个改动通过“保存混音”一次提交。左侧原有 S/M 仍是试听声部选择，与这里的工程混音设置区分。 |
| 版本 | 本次会话内撤销/重做；操作本质为恢复快照并创建新 revision，仍可通过版本列表跨重启查历史；历史版本只读。 |

导入的现有转录没有 clip 的部分显示“未编组 MIDI”事件摘要，不冒充音频波形或可拖片段。先选择声部和循环区间，再按“区间音符编组”，之后才能拖动该 MIDI 片段。跨区间延音、已经属于其他 clip 的事件不会被自动截断或重新分配。新乐器轨道需再选择音色，没有音源时不冒称已发声。

网格使用当前 TimingMap 的分段映射、拍号和弱起；可以关闭吸附或选择音符分辨率。没有节拍图时显示秒钟网格，不能编造固定 BPM。改变音符位置/时值以及移动/复制片段时，受影响音符显式改为源样本锚定并清除过时的记谱位置；原节拍绑定与原始分析保留在旧版本，源录音不移动或改写。纯音高/力度修改保留原时间绑定。音符超出所属片段、片段越出工程、分割跨过延音、裁剪会丢音等情况明确拒绝。

## 保存、播放与并发

制作区不保存第二份工程真相。所有实际操作使用现有 `edits.apply`、`revisions.restore`、`jobs.submit`，与 AI/API/SDK/CLI 共用 Service 校验、幂等和 expected_revision；仍为 51 项领域操作、11 类任务，没有新数据库迁移。新增 `dawEditing.ts` 只负责坐标/网格和编辑请求组装，服务端仍验证整个事务。

拖动时只是预览，松开才提交；取消不生成版本。范围显式列出被修改轨道；轨道、路由和片段编排使用整曲 structural 范围。删除轨道显式移除所属音符、片段、CC、插件、自动化及路由节点/边，不删除 CAS 或原音乐文件。音轨创建在显式路由图存在时连接已确认的主总线，不产生悄悄未连接的乐器轨道。

保存后立即显示服务返回的 revision、停止旧播放、使旧 publication 失效，并刷新父级工程 head。较早轮询不能把界面倒退到保存前快照。并发改 head 时展示冲突，不自动覆盖或盲重试；校验错误展示有限的具体原因。手动撤销栈在外部 head 改变后失效，避免跨过别人的改编。历史版本上的控件不会写入。

**试听仍采用真实 VST3 离线渲染。** 编辑成功表示新版本保存成功，需点“生成试听”，完整渲染完成后才能播放该版本的重建；不是拖音符立即实时发声。参数自动化绘制、录音、音频时间伸缩/变调、任意插件私有窗口、FL Pattern/Channel Rack 的完整工作流尚未实现，不能把外观或基础操作等同完整商业 DAW。
