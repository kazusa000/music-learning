# 自动收起顶栏与侧栏整理

2026-10-19。用户要求工程标题栏和播放工具栏自动收起、提供锁定键，并改善两侧栏的实际使用。

## 顶部工具栏

用户随后明确要求删除重复的工程标题栏，现已直接删除；歌曲名只在窄条出现一次，返回音乐库也放在窄条，“生成重建试听”并入播放工具栏。AutoHideToolbar.tsx 仅保留播放工具栏抽屉。默认自动模式折成 32px 窄条，仍可查看歌曲名、播放时间和快速播放/暂停；鼠标悬停或键盘焦点进入展开，鼠标离开 450ms 后收起。输入/选择控件或键盘可见焦点仍在抽屉内时不自动关闭，Escape 可在未锁定时关闭。隐藏内容使用 hidden/inert，不留在键盘 Tab 顺序中，也不卸载已有控件或改变播放。

右侧锁定按钮让播放工具栏常驻，并在本机记忆；取消锁定恢复自动模式。自动模式展开时覆盖编辑区上方，不来回推动卷帘位置；锁定时正常占据布局空间。工具栏自身也压缩高度。锁定/展开按钮的键盘空格保留按钮行为，其他已有播放快捷键保持。

## 侧栏

- 音轨改成紧凑、可识别的列表：名称和预设各一行，音符数与独奏/静音操作一致对齐；选中和试听状态各自保留，不把点选编辑当作独奏。增益仍在混音台可操作，侧栏去掉重复增益小字。
- 原曲分轨下载收进默认折叠区域。既有选轨、双击卷帘、独奏/静音仍走原功能。
- 右侧内容标签有统一选中状态，支持方向键与 Home/End 切换。AI 区突出对话、讨论范围、声部和时间区间、输入及发送；连接方式和说明收进可展开设置，已有登录选择继续记住。
