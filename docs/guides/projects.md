# 工程、版本与导出

工程保存音轨、片段、音符、插件完整状态、混音和相关素材。原始素材与派生结果由本机数据目录管理，不能通过清空文件夹代替应用内删除。

编辑写入不可变内部修订，当前工程指向最新修订；手动版本用于保留有意义的音乐节点，并可用于比较或回退。AI、界面和脚本共用相同的修订与事务规则。

试听或播放不会替代最终导出。导出操作使用指定的工程版本和混音生成文件，失败时不会把未完成文件作为成功产物。

应用内永久删除会关闭相关播放与任务、解除资源引用并清理属于该工程的数据。操作不自动创建工程备份；仍被其他工程或活动任务使用的共享资源必须保留。

正式数据位于 `data/app-data`，包括 SQLite、内容寻址素材与任务状态。开发测试应使用独立数据目录，不在正式工程试验。

技术入口见[统一接口](../development/unified-api.md)及[本地架构](../architecture/native-daw.md)。
