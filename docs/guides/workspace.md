# 工作台与播放

## 开始工程

主页可以新建编曲或导入音乐。新建编曲设置速度、拍号和长度，从空乐器轨开始；导入音乐先完成整曲预处理，再进入工作台查看与编辑。

进入工程后，顶部加载栏显示当前阶段、已就绪音源数和耗时。「详情」可查看各条音轨；全部就绪后自动收起。失败会保留具体原因与「重新加载」按钮。读取配置或准备原曲音频时使用活动进度条，音源开始加载后按实际就绪数量显示百分比。

## 原曲与重建

导入工程提供原曲参考和重建工程。原曲用于听辨和定位，重建工程中的 MIDI、乐器与混音可以修改。有人声与纯音乐的轨道组成不同，以工程实际结果为准。

选择音轨、片段与音符，再编辑或与 AI 讨论。钢琴卷帘负责音符的音高、起止、时值和力度；编排区负责声部与片段。面板宽高可以拖动调整，轨道列表与编排共用纵向滚动位置。

## 播放与混音

使用播放按钮或空格播放／暂停；文本输入框和模态窗口拥有键盘焦点时，空格按输入或窗口行为处理。播放、定位、逐轨音量、静音与独奏由原生音频引擎执行，可以边播放边调整。

切换乐器需要加载对应插件及采样，声音准备完成后再应用到播放图。大型采样器的冷装载时间受磁盘影响。日常调音量、静音与独奏直接更新混音，不需要导出整首文件。

最终混音文件由显式导出操作产生。保存工程、准备试听和导出文件分别有各自的结果。

架构说明见[本地引擎](../architecture/native-daw.md)；创作工程的网格、笔记和轨道规则见[创作工作区](../architecture/composition-workspace.md)。
