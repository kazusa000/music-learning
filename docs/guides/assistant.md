# AI 对话与工程笔记

工作台侧栏可以新建或切换会话、选择模型，并显示 Markdown 回复。模型可用项来自当前连接的服务目录；思考强度与快速模式是独立设置，随会话偏好保存。

讨论可以围绕整曲、指定声部或明确选择的范围分析和弦、节奏、配器与编曲。发送前查看当前作用范围，避免把旧片段范围带入新的请求。

需要修改时，直接说明目标、声部和范围，例如换音色、改写某段伴奏或调整音符。助手通过统一工程接口执行，操作后回读实际工程状态；声音加载结果与修改保存结果分别反馈。

原曲分析和当前 MIDI 可以作为不同的讨论依据。没有用户明确选择的片段时，不应替用户捏造片段意图；音色选择应查询当前可用条目。

工程笔记与会话分别保存。笔记区支持编辑和 Markdown 预览，助手也可读写同一份笔记，用于记录和声分析、配器思路和待改事项。

技术细节见[会话设置](../architecture/ai-conversation-controls.md)、[创作与共享笔记](../architecture/composition-workspace.md)及[统一接口](../development/unified-api.md)。
