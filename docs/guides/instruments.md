# 音源与试听

## 选择与应用

先选择音轨，再选择乐器类别、具体型号和预设变体，确认后应用。型号代表乐器或具体器材，变体代表它的音色、奏法或设置；不把同一型号的每个预设都列成独立乐器。

Keyscape、Pianoteq、Kontakt 等产品名保持英文。其余展示名称使用中文，并附英文原名；内部 ID、来源名称和预设身份保持原值。

型号和变体提供试听入口。试听使用该条目实际状态生成的短乐句；已有缓存直接播放，未准备好的条目先排队。试听成功、预设验证通过和应用到工程分别有各自的结果。

更换音色会加载插件和完整状态，必要时等待采样就绪。单纯音量、声像、静音和独奏直接更新混音，不重新生成整首音频。

## 音源位置与导入

用户音源库位于 `H:\music\Sound Library`。后续导入统一按乐器、型号、变体归类，不让用户逐个浏览采样库文件夹。

只有完成入库检查的条目才能成为正式可选音色。可选内容以当前音源列表为准。Ample 已取消导入并退库，不再自动恢复其验证或试听任务。

规则与工具入口见[音源入库](../development/instrument-intake.md)。免费插件与采样来源、许可证分别保存在 `config/native-dependencies.json`、`config/instrument-sources.json` 和[第三方说明](../../THIRD_PARTY.md)。
## 独立乐器库

主页进入「乐器库」，按家族、细分乐器、产品来源筛选，或用中文／英文搜索型号和预设，也可以收藏常用乐器。打开型号后，「乐器」页展示外观与声音说明，「插件」页操作真实音源界面；底部键盘可以试弹，A–L 一带的键位也可演奏。

调整会保留为草稿。点击「保存预设」创建或更新个人预设，「另存为」保留另一个版本。出厂预设保留。这一版用于独立试音和制作预设，暂不关联工程音轨。

正常运行 `start.cmd`，在主页点击「乐器库」即可进入，无需另开预览。草稿和个人预设保存在正式应用数据目录的 SQLite 中，不写入工程修订或原厂音源库。

独立工作树的预览入口 `scripts/instruments/open-library.cmd` 仍保留给开发使用。首次正式部署已按 additions-only 方式带入该预览库的草稿，原预览数据库保留。
